# 平行香港：核心模型（第 1 階段，已實作）

> 這份文件描述第 1 階段實際做出來的模型。數字都是**約數**，校準和數據來源見遊戲內「數據來源與模型」及 `src/data/`。

---

## 1. 設計原則

1. **主要操作只有一個**：預算面板的部門撥款。稅率、債務、政策、抉擇都在，但屬次要。
2. **不打斷玩家**：時間一直流動，面板隨時打開、隨時調整。何時暫停由玩家在 ⚙ 設定裡決定。
3. **複雜放在城市裡面**：保養、工程延遲、收入、人口流動、經濟結構由系統計算，玩家觀察結果。
4. **用真實單位**：庫房以億元計，人口以萬人計，公屋輪候以年計，鐵路以公里計。0–100 分的指標只是摘要。
5. **歷史是背景**：大事件照真實日子發生。遊戲中不講「跟歷史一樣／不同」，結局才揭曉。

---

## 2. 核心做法：真實歷史作基準，計算玩家造成的差距

每一個數值都寫成：

```
你的數值 = 真實數值（當月） + 你的決定累積造成的差距
```

- 真實數值來自 `src/data/real.ts` 的年度數據，按月插值。
- 差距來自玩家的撥款、稅率、政策、抉擇，以及這些決定帶來的連鎖反應（人口、樓價、經濟）。
- **完全照真實政府的撥款和抉擇去做，所有差距都是零，結果等於真實的香港**。自動測試會逐年檢查這一點，以及每月的收支是否平衡。

## 5. 預算面板：部門撥款

### 5.1 六個可調部門

| 部門 | 基本額隨甚麼增加 | 高於 100% 建出甚麼（每億元，1997 年價格） | 何時見效 |
|---|---|---|---|
| 房屋及土地 | 公營房屋數量 | 公營單位約 63 個；另有土地可賣作私樓 | 3–7 年；賣地 3 年 |
| 交通及基建 | 鐵路長度 | 鐵路約 1/30 公里 | 5–9 年 |
| 經濟及產業 | 經濟規模 | 本地生產總值長遠增加約 0.5 億 | 0–2 年 |
| 教育 | 學齡及年輕人口 | 專上教育人口比例 +0.0024 個百分點 | 3–7 年 |
| 醫療及社福 | 長者人數和人口 | 病床及安老宿位約 7 個 | 1–2 年 |
| 環境及保育 | 人口和經濟活動 | PM10 −0.015 微克/立方米 | 0–3 年 |

另有**其他開支**（治安、行政等），按人口自動計算，不可調。

### 5.2 撥款水平
- **基本額** = 維持現有服務所需的錢。由真實開支比例推算，並隨你的城市規模調整：例如公營房屋越多保養越貴，長者越多醫療需求越大。
- 滑桿 50%–200%，每月開支 = 基本額 × 撥款水平；工程金額按物價指數調整。
- **高於 100%**：多出的錢按上表轉化為建設，並有邊際遞減：150% 以上的部分只有一半效果。
- **低於 95%**：設施質素逐步下降，最終停在一個由撥款決定的水平：

```
質素目標 = 1 − 1.5 × (95% − 撥款)    （最低 30%）
```

  每年向目標移動約四分之一；撥款回到 95% 以上後，每年回升約五分之一。質素影響對應的指標和吸引力，經濟質素低會拖慢增長。
- **開局撥款**是 1997 年真實政府的估算水平：房屋 130%、交通 125%、經濟 100%、教育 105%、醫療 105%、環境 100%。真實政府各時期的水平見 `src/data/budget.ts`，結局時會跟你的比較。

## 6. 收入與稅率面板

| 收入 | 計算 |
|---|---|
| 薪俸稅 | 真實數額 × (你的稅率 ÷ 真實稅率)^0.7 × 經濟規模比例 |
| 利得稅 | 同上，用利得稅率 |
| 差餉 | 真實數額 × (稅率比例)^0.9 × 住宅數量比例 × √樓價比例 |
| 印花稅 | 真實數額 × 樓價比例 × 辣招倍數 |
| 賣地收入 | 真實數額 × 樓價比例 + 額外賣地（每萬個私樓單位 × 1.2 × 樓價指數，億元） |
| 投資收入 | 真實數額 + （你的儲備 − 真實儲備）× 每年 4% |
| 其他收費 | 真實數額 × 人口比例 |
| 商品及服務稅 | 只在推行時：本地生產總值的 2% |

- 三項可調稅率：薪俸稅（10%–25%）、利得稅（10%–25%）、差餉（3%–8%）。每項有「按當時稅制自動調整」，預設開啟，跟真實稅率變化。
- 市民和企業按「感受到的稅率」反應，每月向實際稅率移動 1/24：利得稅每高 1 個百分點，經濟每年增長慢 0.08 個百分點；薪俸稅和差餉影響吸引力。

---

## 7. 債務面板

- 隨時可發 100／500／1,000 億元的 5 年或 10 年債券。利率 = 當年市場利率 + 0.5% + 8 × 債務佔本地生產總值比例。
- 每月付息，到期一次還本，也可提早還款。
- 庫房跌穿 0 時，自動發 5 年期債券補回並留 300 億緩衝，同時觸發「財政告急」抉擇。
- 債務超過本地生產總值的 30%：**財政崩潰**，任期提早結束。超過 22% 時會先發出警告。

## 8. 政策面板

每項政策有幾個等級。標示「預設」的政策跟隨真實時間表；玩家一改動就由玩家決定，也可以恢復預設。收件匣有相關抉擇在等待時，政策維持抉擇出現前的狀態。

| 政策 | 等級 | 可推行 | 主要效果（每年） |
|---|---|---|---|
| 建屋目標（八萬五） | 不設／溫和／八萬五 | 1997 起 | 公私營單位各 +0.5／+1 萬、樓價 −2%／−4%；1998–2003 年拖慢經濟 |
| 居屋計劃 | 停建／減少／興建 | 1997 起 | 公營單位 +0.35／+0.7 萬 |
| 公私營房屋比例 | 50:50／60:40／70:30 | 1997 起 | 每年 3 萬個新土地單位按比例分配，影響輪候和賣地收入 |
| 簡約公屋 | 不興建／興建 | 2022 起 | 18 個月內每年 +0.6 萬單位 |
| 郊野公園邊陲發展 | 不發展／發展 | 2017 起 | 公私營各 +0.4 萬單位、保護區 −0.8% |
| 樓市辣招 | 不推行／溫和／全面 | 1997 起 | 樓價每年 −0.75%／−1.5%、印花稅 ×1.07／×1.15、經濟略慢 |
| 法定最低工資 | 不設／實施 | 2011 起 | 失業率 +0.3 個百分點、福祉 +2 |
| 長者生活津貼 | 不設／實施 | 2013 起 | 約 60 億元、福祉 +4 |
| 全民退休保障 | 不設／實施 | 2013 起 | 約 250 億元、福祉 +8、吸引力 +2% |
| 空氣污染管制 | 現有／加強／進取 | 1997 起 | PM10 −5／−9 |
| 人才入境計劃 | 不設／一般／大力搶人才 | 1997 起 | 每年多 0.3／5 萬人移入 |
| 產業重點 | 不設／金融／貿易物流／旅遊／創科 | 1997 起 | 該行業每年增長快 1.5 個百分點、約 30 億元 |
| 商品及服務稅 | 不開徵／開徵 | 2006 起 | 收入約本地生產總值的 2%、經濟略慢、福祉 −3 |

福祉、失業率、吸引力、PM10 和保護區這類「水平」效果，約兩年內逐步出現。金額按物價指數調整。

## 9. 人口面板：吸引力與移民

```
每月人口 = 真實人口 + 你造成的差距
差距每月變化 = 0.5 萬 × (吸引力² − 1) + 人才政策差距
```

吸引力是七個因素的乘積，每項以真實香港同一時間為 1：

| 因素 | 計算 |
|---|---|
| 就業機會 | (就業率比例)^1.5 |
| 收入 | (人均本地生產總值比例)^0.5 |
| 住屋 | (輪候比例)^0.08 × (樓價負擔比例)^0.2 × (差餉比例)^0.05 × 屋邨質素 |
| 醫療及教育 | (每千名長者病床宿位比例)^0.1 × 醫療質素 × 專上教育 |
| 環境 | (PM10 比例)^0.1 × 保護區 |
| 稅務 | (薪俸稅比例)^0.2 |
| 政策 | 1 + 政策效果 |

- 新增人口八成屬勞動年齡，一成半是兒童，半成是長者。
- 面板以「吸引人留下／一般／推走人」顯示各因素。
- 反效果：住屋改善會吸引更多人移入，需求跟著上升。

## 10. 經濟

- 本地生產總值 = 真實數值 × 生產力差距 × (就業人數比例)^0.6。
- 五個行業：金融、貿易物流、旅遊、專業服務及創科、本地服務及地產，1997 年比例按真實數據。每年各行業有長期趨勢和歷史衝擊，例如 SARS 時旅遊 −20、疫情時旅遊 −70、金融海嘯時金融和貿易受挫。這些衝擊按真實行業比例校正，所以真實香港的總增長不變；如果你的行業比例不同，受到的衝擊就不同。
- 生產力差距每年變化：
  - 經濟及產業撥款
  - 專上教育人口 × 0.04
  - 鐵路覆蓋（對數比例 × 0.5）
  - 利得稅
  - 經濟設施質素
  - 政策
  - 行業結構
  - 抉擇事件
- 失業率：職位隨生產力和勞動人口變化，移入人口多過職位增長時失業率上升。
- 樓價每月向目標移動 2.5%：

```
樓價目標 = 2 × [ln(住戶比例) − ln(單位供應比例)] + ln(人均收入比例) + 政策累積效果
```

  單位供應 = 私樓 + 一半公營房屋。

## 11. 需求面板與市民最關心

六個範疇：住屋、就業、交通、醫療安老、教育、環境。每項顯示數字（例如住戶對單位、公屋輪候、失業率、每千名長者病床宿位）、一句總結和**原因**。原因只用玩家自己的數字和決定生成，例如「房屋及土地撥款只有 85%，低於維持現有服務所需」、「過去三年人口增加 12 萬」、「預計未來三年有約 4.8 萬個公營單位落成」。

「市民最關心」取嚴重程度最高的三項。

## 14. 結局與評級

- 2026 年 10 月回到現在，或因財政崩潰提早結束。
- **你的香港 vs 真實香港**：六項指標、財政儲備減債務、人口的走勢圖。
- **2026 年的數字**：人口、財政儲備、債務、人均本地生產總值、失業率、公屋輪候、樓價指數、鐵路、每千名長者病床及宿位、專上教育、PM10、預期壽命。
- **歷史揭曉**：每個抉擇你選了甚麼、歷史上選了甚麼、後來怎樣。
- **撥款比較**：每五年的平均撥款水平，你對比真實政府（估算）。
- **評分** = 六項指標與真實的差距總和 + 財政分：
  - 財政分：儲備減債務比真實多，每 1,500 億 +1 分，最多 +10；比真實少，每 400 億 −1 分，最多 −20。
  - 評級：S ≥ 30、A ≥ 12、B ≥ −5、C ≥ −25，其餘 D；財政崩潰一律 D。
- 城市稱號取決於差距最大的指標或指標組合，例如「安居之城」「新市鎮之城」「儲備之城」；與真實差不多就是「歷史重演」。

## 16. 尚未做／之後再做

- 官方數據取代約數（第 2 階段）。
- 像素地圖（第 3 階段）。
- 舊樓老化、施政阻力、追蹤市民、里程碑（第 4 階段）。
