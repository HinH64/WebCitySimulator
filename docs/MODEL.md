# 平行香港：核心模型（第 1 階段，草案）

> 這份文件定義第 1 階段（核心玩法）要重做的內容。確認後才開始寫程式。
> 文中的數字都是**約數**，用來說明量級；實際數值會在校準時調整，並在數據來源頁列明。

---

## 1. 設計原則

1. **主要操作只有一個**：資源分配，也就是預算面板的部門撥款。其他操作（稅率、債務、政策、抉擇）都在，但屬次要。
2. **不打斷玩家**：時間一直流動，所有面板隨時打開、隨時調整，遊戲不會停下來等你。何時暫停由玩家在設定裡決定。
3. **複雜放在城市裡面**：保養開支、工程延遲、人口流動、經濟結構都由系統計算，玩家只需觀察結果。
4. **用真實單位**：庫房以億元計，人口以萬人計，公屋輪候以年計，鐵路以公里計。0–100 分的指標只是摘要。
5. **歷史作為背景**：大事件照真實日子發生；玩家的決定只改變後果。「跟歷史一樣／不同」留到結局才揭曉。

## 4. 兩個主要數值

### 4.1 庫房（財政儲備，億元）
```
每月庫房變化 = 收入 − 開支 − 利息 + 發債所得 − 還債
```
- 起始約 4,500 億（1997–98 年度末真實為 4,575 億）。
- 庫房跌到 0 時，不夠的錢會自動發債。債務到上限 → **財政崩潰**，任期提早結束。

### 4.2 人口（萬人）
```
每月人口變化 = 出生 − 死亡 + 單程證移入 + 其他移入 − 移出
```
- 起始 649 萬。分三個年齡組：0–14、15–64、65+，用來計算勞動人口和長者需求。
- 出生率、死亡率、單程證人數用真實歷史數據（外生），玩家影響不大。
- **其他移入和移出由吸引力決定**（見第 9 節），是玩家可以影響的部分。

## 5. 預算面板：部門撥款（主要操作）

採用撥款水平（Cities: Skylines 的做法）。

### 5.1 六個可調部門

| 部門 | 包括 | 基本額取決於 | 擴建（高於 100%）會建出 |
|---|---|---|---|
| 房屋及土地 | 公屋、居屋、土地平整 | 現有公屋單位的保養 | 平整土地 → 公屋、居屋單位 |
| 交通及基建 | 鐵路、道路、口岸 | 現有鐵路和道路的保養 | 新鐵路（公里）、道路容量 |
| 經濟及產業 | 招商、產業支援、旅遊推廣、創科 | GDP 規模 | 產業競爭力（提高經濟增長） |
| 教育 | 中小學、專上教育 | 學齡人口 | 專上學額、教育質素 |
| 醫療及社福 | 醫院、安老、社會保障 | 人口和長者人數 | 病床、安老宿位、服務質素 |
| 環境及保育 | 空氣、廢物、郊野公園 | 人口和經濟活動 | 減排、綠化 |

另有**其他開支**（治安、行政、對外事務等），按人口自動計算，不可調整，約佔總開支兩成。

### 5.2 撥款水平怎樣運作
- 每個部門有「**基本額**」，即維持現有服務所需的錢。基本額會隨建設量和需求自動增加：鐵路越長，保養越貴；長者越多，醫療需求越大。
- 滑桿範圍 **50%–200%**，每個部門每月開支 = 基本額 × 撥款水平。

| 撥款水平 | 效果 |
|---|---|
| 低於 70% | 服務質素急跌：輪候時間急升，設施失修 |
| 70%–90% | 質素慢慢下滑 |
| 90%–100% | 大致維持 |
| 高於 100% | 多出的錢用於擴建。擴建有邊際遞減（例如每年建屋量有上限），並有工程延遲 |

- 面板即時顯示：每個部門的開支和佔總開支的 %、總開支、預計收入、每月盈餘或赤字。
- 調整由**下個月**起生效。

### 5.3 工程延遲（約數）

| 建設 | 由撥款到見效 |
|---|---|
| 公屋（已有熟地） | 約 5 年 |
| 公屋（新平整土地） | 約 8–10 年 |
| 鐵路 | 約 7–10 年 |
| 病床、安老宿位 | 約 1–3 年 |
| 專上學額、教育質素 | 約 3–8 年 |
| 減排 | 約 1–5 年 |
| 產業競爭力 | 約 1–3 年 |

施工中的項目列在各面板的「興建中」清單，顯示預計完成年份。

### 5.4 參考起始比例（1997 年，約數，校準用）

| 房屋及土地 | 交通及基建 | 經濟及產業 | 教育 | 醫療及社福 | 環境及保育 | 其他（不可調） |
|---|---|---|---|---|---|---|
| 8% | 14% | 5% | 20% | 25% | 4% | 24% |

開局時六個部門都是 100%，也就是按真實比例維持現有服務。

## 6. 稅率面板

對應 SimCity 的住宅、商業、工業稅，按香港稅制改為三項：

| 稅項 | 起始（1997） | 範圍 | 影響收入 | 其他影響（數年後才慢慢出現） |
|---|---|---|---|---|
| 薪俸稅標準稅率 | 15% | 10%–25% | 隨就業人數和工資 | 稅率高 → 人才吸引力下降 |
| 利得稅 | 16.5% | 10%–25% | 隨企業盈利 | 稅率高 → 企業投資和經濟增長放慢 |
| 差餉 | 應課差餉租值 5% | 3%–8% | 隨物業數量和租金 | 稅率高 → 住屋負擔加重 |

另外還有兩項收入，玩家不能直接調：
- **印花稅**：隨樓價和成交量變化，受「辣招」政策影響。
- **賣地收入**：隨土地供應和樓價變化，土地供應由房屋及土地撥款決定。

還有：
- **投資收入**：庫房的錢有投資回報，按歷史回報率計，約 3%–5%。
- **其他收費**。

## 7. 債務面板

- 隨時可以發債：選金額和年期（5 年或 10 年）。錢即時入庫，之後每月付息，到期還本。
- 利率 = 當年市場利率（真實歷史數據）+ 息差。息差隨債務水平上升。
- 債務上限：GDP 的 30%，接近上限時會發出警告。
- 庫房見底時，系統會自動發短期債維持運作，並觸發「財政告急」事件。

## 8. 政策面板（長期政策）

長期生效的開關，每項有每年成本或收入，以及持續的效果。部分政策要到某一年才可以開；部分由抉擇事件開關。

| 政策 | 可用時間 | 每年成本／收入 | 主要效果 |
|---|---|---|---|
| 八萬五建屋目標 | 1997 起 | 增加房屋開支 | 公屋和私樓供應大增，樓價下跌；經濟低迷時會加深衰退 |
| 居屋計劃 | 1997 起（開局時開） | 房屋開支 | 中低收入家庭置業，減輕公屋輪候；會分薄私樓需求 |
| 樓市辣招 | 2010 起 | 增加印花稅收入 | 壓抑炒賣和成交量，樓價升幅放慢 |
| 最低工資 | 2011 起 | 少量 | 基層收入上升；低技術職位略減 |
| 長者生活津貼 | 2013 起 | 社福開支 | 長者生活改善 |
| 全民退休保障 | 2015 起 | 大量社福開支 | 長者生活大幅改善；長遠財政壓力大 |
| 人才入境計劃 | 2006 起 | 少量 | 高技術人口移入增加；住屋需求上升 |
| 公私營房屋比例 | 2014 起（60:40／70:30） | — | 決定新土地用作公營房屋或賣地的比例 |
| 簡約公屋 | 2022 起 | 房屋開支 | 3 年內提供過渡單位，縮短輪候 |
| 郊野公園邊陲發展 | 2017 起 | — | 增加可建屋土地；環境下降 |

大型項目（十大基建、明日大嶼、北部都會區）由抉擇事件啟動，啟動後列在「興建中」清單。

## 9. 人口面板：吸引力與移民

參考 Forrester 的城市模型：土地有限，人口流動由吸引力推動。

```
吸引力 = 就業 × 收入 × 住屋 × 服務 × 環境 × 稅務
（每項以 1997 年水平為 1.0）
其他移入 = 基本移入 × 吸引力 × 人才政策加成
移出     = 基本移出 ÷ 吸引力 + 歷史事件（例如移民潮）
```

| 因素 | 由甚麼決定 |
|---|---|
| 就業 | 失業率 |
| 收入 | 實質工資增長 |
| 住屋 | 樓價入息比、公屋輪候 |
| 服務 | 醫療和教育質素 |
| 環境 | 空氣質素 |
| 稅務 | 薪俸稅率 |

- 面板顯示每項因素的高低，以及每月移入和移出人數。
- **反效果**：住屋改善會吸引更多人移入，需求跟著上升，所以輪候時間未必下降。這是 Forrester 的觀點，也很貼近香港。

## 10. 需求面板（需求與供應）

參考 SimCity 的 RCI 表和 Cities: Skylines II 的需求頁，每項都顯示需求、供應和原因。

| 範疇 | 需求 | 供應 | 顯示 |
|---|---|---|---|
| 住屋 | 住戶數（人口 ÷ 平均住戶人數） | 公屋、居屋、私樓單位 | 短缺或空置、公屋輪候宗數和年期、樓價入息比 |
| 就業 | 勞動人口 | 各行業職位 | 失業率、職位空缺 |
| 交通 | 出行需求（人口、職位分佈） | 鐵路公里和道路容量 | 擠迫度、平均通勤時間 |
| 醫療安老 | 人口、長者人數 | 病床、安老宿位 × 質素 | 輪候時間 |
| 教育 | 學齡和適齡人口 | 學額 × 質素 | 專上教育參與率 |
| 環境 | 經濟活動和車輛造成的污染 | 減排和綠地 | PM10 濃度、綠地比例 |

**原因**由系統自動從最大的影響因素生成，例如：

> 住屋短缺 3.2 萬個單位：5 年前房屋撥款只有 85%，加上過去兩年淨移入 8 萬人。

## 11. 經濟

- GDP 分五個行業：**金融**、**貿易物流**、**旅遊**、**專業服務及創科**、**本地服務（包括地產）**。1997 年的比例按真實數據設定。
- 每個行業的增長 = 歷史基本增長 + 經濟及產業撥款效果 + 政策效果 + 歷史衝擊。
- **歷史衝擊打擊不同行業**：

| 事件 | 主要打擊 |
|---|---|
| 亞洲金融風暴（1997–98） | 金融、本地服務 |
| SARS（2003） | 旅遊、本地服務 |
| 個人遊（2003 起） | 旅遊增長 |
| 金融海嘯（2008） | 金融、貿易 |
| 疫情（2020–22） | 旅遊、本地服務 |

  所以同一場衝擊，會因你的經濟結構而有不同後果。
- 職位按行業產出計算，再跟勞動人口比較得出失業率。
- 收入跟經濟掛鈎：利得稅跟企業盈利，薪俸稅跟就業和工資，印花稅和賣地收入跟樓價。

## 12. 發展指標（摘要，0–100）

指標用「結果」命名，跟部門名稱分開。每項由真實單位的數據換算，並按人口攤分：

| 指標 | 由甚麼計算 |
|---|---|
| 經濟實力 | 人均 GDP、失業率 |
| 安居 | 公屋輪候年期、樓價入息比、人均居住面積 |
| 出行 | 鐵路覆蓋（每百萬人公里數）、擠迫度 |
| 健康與福祉 | 醫療安老輪候、預期壽命 |
| 人才與創新 | 專上教育參與率、創科行業比重 |
| 宜居環境 | PM10、綠地比例 |

指標旁邊會顯示上升或下跌的箭頭。點一下指標，就打開需求面板看原因。

## 13. 事件與收件匣

| 類型 | 出現方式 | 例子 |
|---|---|---|
| 歷史事件 | 照真實日子發生，有具體影響（行業、人口、收入） | SARS、金融海嘯、山竹 |
| 歷史抉擇 | 放進**收件匣**，有限期（約 3 個月）。到期未回覆，自動選「維持現狀」 | 八萬五、入市干預、停建居屋、十大基建、北部都會區 |
| 平行時空事件 | 由你的城市狀況觸發 | 財政告急、供應過剩樓價急跌、人才流失、司法覆核 |
| 年度報告 | 每年 1 月顯示上一年的摘要 | 收支、人口變化、落成量 |

- 抉擇的選項會開關政策、啟動大型項目，或直接影響數值。
- 抉擇時**不顯示**歷史上的真實選擇，結局時才一併揭曉。
- 如果「抉擇事件時暫停」設定為開，收到抉擇時會自動暫停。

## 14. 結局

- 2026 年 10 月回到現在；或因財政崩潰提早結束。
- **你的 2026 vs 真實 2026**：人口、庫房、債務、人均 GDP、失業率、公屋輪候、樓價入息比、鐵路公里、PM10、預期壽命。
- **歷史揭曉**：每個抉擇你選了甚麼、歷史上選了甚麼、後來發生了甚麼。
- **你的預算 vs 真實預算**：各部門開支比例的走勢對比。
- 城市稱號和 S–D 評級：按指標、庫房和人口相對真實 2026 的表現評定。
- 走勢圖：庫房、人口和六項指標，你的對比真實。

## 15. 校準：怎樣確保模型接近真實

模型改為從實際數字開始逐年推算，所以不再保證「完全跟隨歷史 = 完全等於歷史」。改用**歷史基準玩法**校準：

1. **輸入真實做法**：各部門撥款按真實開支比例、真實稅率、政策在真實日子開關、抉擇選真實選項。
2. **外生歷史數據**：出生率、死亡率、單程證人數、利率、各行業的歷史增長和衝擊、物價指數。
3. **要求**：用歷史基準玩法跑一局，主要數字要落在真實數字的誤差範圍內。這會寫成自動測試：

| 數據 | 容許誤差 |
|---|---|
| 人口 | ±3% |
| 財政儲備 | ±15% |
| 失業率 | ±1.5 個百分點 |
| 公屋輪候 | ±1 年 |
| 鐵路公里 | ±5% |
| 樓價指數 | ±20% |

4. **平衡測試**：用多種玩法各自動跑多局，例如全部 100%、全押房屋、大幅減稅、不斷發債。要確認：沒有必勝玩法；財政崩潰只會在明顯亂來時發生；不同玩法會得出不同的城市稱號。

## 17. 第 1 階段的工作次序

1. **引擎**：每月計算；庫房、人口（三個年齡組）、六個部門和建設量、收入、債務、吸引力和移民、需求與供應、經濟五行業、發展指標。
2. **數據和校準**：整理約數，令歷史基準玩法通過誤差測試。
3. **事件**：收件匣、政策開關、大型項目、年度報告。
4. **介面**：頂部欄、六個面板、⚙ 設定、需求原因、結局改版。
5. **測試**：決定性、會計恆等（每月庫房變化必須等於收入減開支）、歷史基準校準、平衡測試；並在瀏覽器實際玩一整局。

原型的歷史事件文字、抉擇內容和介面元件會盡量沿用。
