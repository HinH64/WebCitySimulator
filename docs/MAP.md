# 第 3 階段：像素地圖（計劃）

> 按城市的發展**自動建造**香港地圖。玩家不用自己放建築；每局的發展不同，地圖也不同。
> 完成標準（PLAN.md 第 6 節）：地圖隨發展自動變化，不同玩法看得出分別。

---

## 1. 原則

1. **跟模型一樣是「真實 + 差距」**：照歷史玩，2026 年的地圖就是真實香港的土地用途；1997 年的地圖由現在的土地用途減去 1997 年後的真實發展而成。玩家多建或少建的部分，才在地圖上跟真實不同。
2. **地圖只負責顯示，不改變模擬**：地圖讀取城市狀況（房屋單位、鐵路、保護區、行業、人口、樓價、空氣），不會反過來影響任何數字。這樣第 1、2 階段的歷史回測和平衡測試完全不受影響。
3. **同一種子加同樣操作，地圖必定相同**：選地、選線只用城市狀況和種子，不用其他隨機數。
4. **數據盡量可以直接下載**：底圖由下載程式產生（像 `npm run data:official`），結果寫入原始碼，建置時不用連網。1997 年後的發展項目要人手整理（像歷史事件一樣），每項註明出處。

## 2. 數據

### 2.1 底圖：規劃署《香港土地用途》2025

- 來源：規劃署「土地用途網格」（Raster Grids on Land Utilization），2018–2025 年，每年一份，10 米解像度，放在空間數據共享平台（CSDI）。
- 下載方法：CSDI 的直接下載連結被防火牆擋住（HTTP 403），但同一份數據的 **WMS 地圖服務可以用**。已經試過：`GetMap` 用香港 1980 方格網（EPSG:2326，範圍東 800000–863750、北 800000–848000）可以輸出指定大小的圖，每個像素的灰度就是土地用途代碼（0–92）。
- 下載程式 `scripts/fetch-map.mjs`：分塊下載 10 米或 50 米的圖，按每格的**多數類別**縮成遊戲網格，寫入 `src/data/mapBase.ts`（壓縮編碼，約幾十 KB）。
- 要做：確認代碼與類別的對照，例如用 `GetFeatureInfo` 在已知地點取值，再對照規劃署公布的類別表。

遊戲用的地塊類別（由規劃署類別合併）：

| 地塊 | 規劃署類別 |
|---|---|
| 海 | 土地範圍以外（代碼 0） |
| 水塘、河流 | 水體 |
| 郊野／綠地 | 林地、灌木林、草地、紅樹林及沼澤、荒地 |
| 農地、魚塘 | 農業用地、魚塘／基圍 |
| 鄉村 | 鄉郊居所 |
| 公營房屋 | 公營住宅 |
| 私人住宅 | 私人住宅 |
| 商業 | 商業／商貿及辦公室 |
| 工業 | 工業用地、工業邨／科學園、貨倉及露天貯物 |
| 政府、社區 | 政府、機構及社區設施（醫院、學校等） |
| 休憩 | 休憩用地及康樂 |
| 道路 | 道路及交通設施 |
| 鐵路 | 鐵路 |
| 機場、港口 | 機場、港口設施 |
| 其他 | 墳場、公用設施、空置地／建築中、其他 |

### 2.2 1997 年後的發展項目（人手整理）

一份清單 `src/data/mapProjects.ts`，每項有：名稱、類別、落成年份（可以分期）、範圍（網格上的多邊形，或「這個範圍內 2025 年是住宅的格」）、出處。照歷史玩時按年份逐項出現。例子：

- **填海和新區**：赤鱲角機場（1998 年 7 月啟用）、西九龍、中環灣仔填海、啟德、將軍澳南、港珠澳大橋香港口岸人工島、迪士尼樂園（2005）。
- **新市鎮和大型屋邨**：東涌、天水圍北、將軍澳、馬鞍山、安達臣道、洪水橋及古洞北的首批項目。
- **鐵路**：東涌綫和機場快綫（1998）、將軍澳綫（2002）、西鐵（2003）、馬鞍山綫（2004）、落馬洲支綫（2007）、九龍南綫（2009）、西港島綫（2014）、觀塘綫延綫和南港島綫（2016）、高鐵（2018）、屯馬綫（2020–21）、東鐵過海段（2022）。

### 2.3 鐵路站

- 地底鐵路不會出現在土地用途圖，所以鐵路線用「站與站之間的連線」來畫。
- 站的坐標：地政總署 iGeoCom（GeoJSON／CSV，在 CSDI）有港鐵站，但同樣要找可用的下載途徑（WMS／API）。找不到就人手整理約 100 個站的方格網坐標，註明出處。

### 2.4 候選發展地（玩家建得比真實多時用）

真實提出過、但未建或較遲才建的地方，例如：東涌東填海、交椅洲人工島、北部都會區（古洞北、粉嶺北、新田、洪水橋）、元朗南、將軍澳 137 區、屯門西、郊野公園邊陲的幾幅地（給「郊野公園邊陲建屋」政策用）。鐵路候選：北環綫、東九龍綫、屯門南延綫、洪水橋站、南港島綫西段、北港島綫。

## 3. 由城市狀況決定地圖

地圖每年 1 月（和結局時）按城市狀況重新計算：

| 城市狀況 | 地圖上的變化 |
|---|---|
| 公營、私人房屋單位比真實多（`dev.publicUnits`、`dev.privateUnits`） | 按優先次序在候選地起新屋邨（有鐵路的地方先建）；每格代表的單位數按 2025 年真實數字校準 |
| 比真實少 | 真實的屋邨延遲出現，最遲落成的先延遲 |
| 鐵路比真實長或短（`dev.rail`） | 候選鐵路線提早通車，或真實的新線延遲 |
| 保護區比例變化（郊野公園邊陲建屋） | 郊野公園邊陲的綠地變成住宅 |
| 行業比重跟真實不同 | 金融多：商業區向外擴；貿易物流多：貨倉和港口擴大；創科多：科學園、數碼港一類用地增加；旅遊多：酒店和景點用地增加 |
| 空氣（PM10） | 整張地圖加上灰霧，越污染越濃 |

**圖層**（按掣切換）：

- 人口密度：按區議會分區的人口（統計處數據），再按你的城市跟真實的人口差距縮放。
- 樓價：按港島、九龍、新界的樓價水平乘上你的樓價指數。
- 鐵路覆蓋：離鐵路站 500 米內的地方。

## 4. 顯示

- **網格大小**：建議每格 250 米，全港約 255 × 192 格。另一個做法是每格 500 米（128 × 96 格），格子較粗，但手機不用放大也看得清。
- **畫法**：Canvas，每格畫成一個小方塊，整數倍放大（保持像素感）；可以放大、拖動。只在地圖改變（每年一次）或切換圖層時重畫。
- **遊戲畫面**：
  - 桌面：新聞欄上方加地圖（可收起），或「新聞／地圖」切換。
  - 手機：底部分頁加「地圖」。
  - 新項目落成時，地圖上閃一下；城市新聞（例如「新屋邨入伙」）可以按一下，跳到地圖上的位置。
- **結局**：「你的香港 vs 真實香港」兩張 2026 年地圖並排，加年份拉桿，可以由 1997 年播到 2026 年。
- **顏色**：先用跟現在介面一致的平實配色（參考規劃署圖例）；「遊戲風格」的美術方向（例如懷舊模擬遊戲）可以在這個階段一併決定，見第 7 節。

## 5. 測試

- 照歷史玩：1997 年地圖等於「底圖減去所有真實項目」；2026 年地圖等於 2025 年的底圖。
- 同一種子加同樣操作，地圖逐格相同。
- 不同玩法看得出分別，例如：大力建屋，住宅格比真實多；郊野公園邊陲建屋，綠地格比真實少；鐵路撥款多，鐵路格比真實多。
- 效能：每年重新計算地圖少於 20 毫秒；重畫一次少於一幀（16 毫秒）。

## 6. 分步完成

| 步 | 內容 | 完成時 |
|---|---|---|
| **3a 數據** | `scripts/fetch-map.mjs` 下載規劃署土地用途並網格化；確認類別代碼；整理 1997 年後的發展項目、鐵路站、候選發展地 | 可以畫出 1997 年和 2025 年的真實香港 |
| **3b 引擎** | `mapAt(state)`：由城市狀況計算地圖（純函數，不影響模擬）；第 5 節的測試 | 測試通過；不同玩法地圖不同 |
| **3c 遊戲畫面** | Canvas 地圖、放大和拖動、三個圖層、桌面和手機版面、新項目提示 | 可以邊玩邊看地圖 |
| **3d 結局** | 兩個香港的地圖並排、年份拉桿 | 結局可以比較地圖 |
| **3e 美術**（可選） | 決定遊戲的視覺風格，地圖和介面一併調整 | — |

## 7. 待決定

1. **格子大小**：250 米（較精細，手機要放大）還是 500 米（較粗，手機一眼看到全港）？
2. **遊戲畫面的版面**：地圖放在新聞上方、「新聞／地圖」切換，還是地圖做主角、新聞縮到旁邊？
3. **美術風格**：先用平實配色，還是趁這個階段開始做遊戲風格？
4. **1997 年後的發展項目要人手整理**（約 30–50 項，每項註明出處）。這跟第 2 階段「只用可以直接下載的數據」不同，但地圖沒有其他方法知道 1997 年的樣子。

## 8. 風險

- CSDI 的 WMS 也可能改版或被擋：下載結果寫入原始碼，所以不影響建置；只是更新底圖時要另想辦法。
- 規劃署的土地用途是「概括分佈」，不適合精細分析；用在 250 米的遊戲格子上足夠。
- 規劃署的類別定義偶有更改，不同年份不能直接比較；所以只用一年（2025）做底圖，1997 年由項目清單倒推。
