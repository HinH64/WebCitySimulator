# 第 3 階段：像素地圖（計劃）

> 按城市的發展**自動建造**香港地圖。玩家不用自己放建築；每局的發展不同，地圖也不同。
> 完成標準（PLAN.md 第 6 節）：地圖隨發展自動變化，不同玩法看得出分別。
> 3a–3d 已完成；3e 先聚焦「看得見自己建成的城市」，整體版面美術押後。詳見 [ART.md](ART.md)。
> 3e.1 的獨立比較樣板保留在 `/city-study.html`（[CITY-STUDY.md](CITY-STUDY.md)）；3e.2 已把 2.5D 接入遊戲，見 [CITY-MAP.md](CITY-MAP.md)。更多建築素材及鐵路細節押後，3e.3 裝置與效能驗證待完成。

## 1. 原則

1. **跟模型一樣是「真實 + 差距」**：照歷史玩，2026 年的地圖就是真實香港的土地用途；1997 年的地圖由現在的土地用途減去 1997 年後的真實發展而成。玩家多建或少建的部分，才在地圖上跟真實不同。
2. **地圖只負責顯示，不改變模擬**：地圖讀取城市狀況（房屋單位、鐵路、保護區、行業、人口、樓價、空氣），不會反過來影響任何數字。這樣第 1、2 階段的歷史回測和平衡測試完全不受影響。
3. **同一種子加同樣操作，地圖必定相同**：選地、選線只用城市狀況和種子，不用其他隨機數。
4. **數據盡量可以直接下載**：底圖由下載程式產生（像 `npm run data:official`），結果寫入原始碼，建置時不用連網。1997 年後的發展項目要人手整理（像歷史事件一樣），每項註明出處。

## 2. 數據

### 2.1 底圖：規劃署《香港土地用途》2025

- 來源：規劃署「土地用途網格」（Raster Grids on Land Utilization），2018–2025 年，每年一份，10 米解像度，放在空間數據共享平台（CSDI）。
- 下載方法：CSDI 的直接下載連結被防火牆擋住（HTTP 403），帶 SLD 樣式的請求也被擋，但同一份數據的 **WMS 地圖服務可以用**。
- 下載程式 `scripts/fetch-map.mjs`（`npm run data:map`，已完成）：
  - 用香港 1980 方格網（EPSG:2326，東 800000–863750、北 800000–848000），以 25 米間距分 9 塊下載 `GetMap` 圖。
  - 伺服器把代碼 0–92 線性拉伸成灰度（代碼 0 是灰度 2，代碼 92 是灰度 255），所以灰度可以直接換算代碼。要加 `transparent=true`，否則最深的幾級灰度（代碼 0–2：海、私人住宅、公營住宅）都會變成黑色。
  - 每個灰度用 `GetFeatureInfo`（回傳該點的代碼）在均勻範圍內抽樣核對換算，不吻合就停止。
  - 每格 250 米取最多的用途；道路和鐵路很幼但到處都有，所以要佔一半以上才算。
  - 寫入 `src/data/mapBase.ts`（遊程編碼，約 13 KB）。資料保留 25 種地塊；畫圖時可以再合併，例如林地、灌木和草地都畫成綠色。
- 各代碼的面積跟規劃署的統計（2021 年 CSV）吻合，例如私人住宅 27.9、公營住宅 18.2、鄉郊居所 34.6 平方公里。

遊戲用的地塊類別（由規劃署類別合併）：

| 地塊 | 規劃署類別 |
|---|---|
| 海 | 土地範圍以外（代碼 0） |
| 水塘、河流 | 水體 |
| 郊野／綠地 | 林地、灌木林、草地、紅樹林及沼澤、荒地 |
| 農地、魚塘 | 農業用地、魚塘／基圍 |
| 鄉村 | 鄉郊居所 |
| 公營房屋 | 公營住宅 |
| 私人住宅 | 私人住宅 |
| 商業 | 商業／商貿及辦公室 |
| 工業 | 工業用地、工業邨／科學園、貨倉及露天貯物 |
| 政府、社區 | 政府、機構及社區設施（醫院、學校等） |
| 休憩 | 休憩用地及康樂 |
| 道路 | 道路及交通設施 |
| 鐵路 | 鐵路 |
| 機場、港口 | 機場、港口設施 |
| 其他 | 墳場、公用設施、空置地／建築中、其他 |

### 2.2 1997 年後的發展項目（人手整理，已完成）

`src/data/mapProjects.ts` 的 `MAP_PROJECTS`，共 18 項。每項有：
- 範圍：一個多邊形，加上「2025 年是哪幾類用地的格才算」。例如古洞北只算建造中的格，所以不會把上水、粉嶺原有的屋邨算進去。
- 1997 年 7 月的樣子，例如海、空地、啟德機場。
- 之後每一步的日期和完成比例：由起點向外擴展，例如將軍澳由將軍澳站開始。
- 出處。

項目：赤鱲角機場、三跑道系統、港珠澳大橋香港口岸人工島、東涌東填海、東涌新市鎮、竹篙灣迪士尼、西九龍填海區、啟德、將軍澳市中心及南部、天水圍北、安達臣道、白石角科學園、烏溪沙、九號貨櫃碼頭、數碼港、落馬洲河套、古洞北及粉嶺北、洪水橋。少於幾格的發展（例如中環灣仔填海）在 250 米的格子上看不出，沒有列入。

`src/engine/map.ts` 的 `realMapAt(t)` 由 2025 年底圖逐項倒推。測試會檢查：2026 年等於底圖，1997 年啟德是機場、赤鱲角仍在建造、三跑道所在仍是海；項目之間沒有重疊。

### 2.3 鐵路（已完成）

- 站的坐標：地政總署 iGeoCom（香港地圖服務的直接下載連結），99 個鐵路站和 68 個輕鐵站，本身就是香港 1980 方格網坐標，寫入 `src/data/mapStations.ts`。
  - 這個網站沒有提供中繼證書，所以下載程式會由證書上列明的 eCert 網址下載中繼證書，並確認它由 Node 內置的香港郵政根證書簽發。證書驗證沒有關掉。
- 路線：`RAIL_ROUTES` 共 25 段，每段是一串站名和通車日期，例如東涌綫 1998 年 6 月、屯馬綫 2021 年 6 月；觀塘綫經東區海底隧道往鰂魚涌的一段 2002 年改由將軍澳綫行走。
- 地底鐵路不會出現在土地用途圖，所以畫成站與站之間的直線。高鐵全段在地底，只畫西九龍站。
- 輕鐵只畫站（天水圍北各站 2003 年 12 月起出現），連線未畫。

### 2.4 候選發展地和候選鐵路（已完成）

- `CANDIDATE_SITES`：13 幅，各有用途（房屋、金融、貿易物流、旅遊、創科）和最早可以動工的日期。房屋：東涌東、古洞北、粉嶺北、洪水橋、元朗南、將軍澳 137 區、交椅洲人工島；行業：新田科技城（創科）、九龍東商業區（金融）、屯門西物流區（貿易物流）、欣澳旅遊區（旅遊）；郊野公園邊陲兩幅（大欖、馬鞍山），只給「郊野公園邊陲建屋」政策用。
- `CANDIDATE_ROUTES`：9 條，來自《鐵路發展策略 2014》和「明日大嶼願景」，例如洪水橋站、古洞站、東九龍綫、北環綫。未建的站用約數坐標。

## 3. 由城市狀況決定地圖

`cityMapAt(state)`（`src/engine/map.ts`，已完成）由同一個月的真實地圖開始，只改城市跟真實不同的地方：

| 城市狀況 | 地圖上的變化 |
|---|---|
| 公營、私人房屋單位比真實多（`dev.publicUnits`、`dev.privateUnits`） | 每格代表的單位數按 2025 年的存量和格數校準（公營約 3 千、私人約 2 千個）。多出的格依次放在：郊野公園邊陲（如果城市放棄了保護區）→ 真實香港較遲才建的屋邨（即提早建成）→ 候選發展地（最早可以動工的先用）。公營和私人按各自欠缺的數目交替分配 |
| 比真實少 | 最遲落成的真實屋邨先變回落成前的樣子（例如建造中） |
| 鐵路比真實長或短（`dev.rail`） | 長：較遲的真實路線提早通車，之後是候選路線；短：最新的路線先取消，但只限五年內真實通車的路線（4d 加入，避免早已行駛多年的路線消失）。差距夠一條路線的一半才計 |
| 保護區比例比真實低（例如郊野公園邊陲建屋） | 按比例把郊野公園邊陲兩幅地的綠地變成建造中，再用來起屋 |
| 行業比重比真實高 | 對應的候選地按比例發展，高出 50% 就全幅用完：金融是九龍東商業區，貿易物流是屯門西貨倉和港口，旅遊是欣澳景點和酒店，創科是新田科技城 |
| 空氣（PM10） | 回傳 0–1 的灰霧濃度（PM10 20 以下是 0，70 以上是 1），畫圖時加上 |

照歷史玩（關掉隨機新聞）時，城市地圖等於真實地圖。行業比重比真實低時，地圖暫時不變。

**圖層**（按掣切換）：

- 人口密度：按區議會分區的人口（統計處數據），再按你的城市跟真實的人口差距縮放。
- 樓價：按港島、九龍、新界的樓價水平乘上你的樓價指數。
- 鐵路覆蓋：離鐵路站 500 米內的地方。

## 4. 顯示

- **網格大小**：每格 250 米，全港約 255 × 192 格。
- **畫法**（`src/ui/MapView.tsx`、`mapGeometry.ts`、`mapRenderer.ts`，3e.2 已整合）：
  - 土地用途預設 2.5D，也可選俯視。全港總覽等縮小視野（每格不足 5 像素）每格一點、用圖例顏色，整個城市一次畫出；放大後換成住宅、商業、貨倉等示意樓群，吊臂只用當時工程資料。1997 年 7 月後才建成的格子（真實或城市自己的，包括比歷史多重建的舊樓）用較高、顏色鮮明、窗戶較亮的款式；之前的樓較矮、色調較灰（3f.1）。樓群不是逐棟真實建築。
  - 人口密度、樓價及鐵路覆蓋仍用 255 × 192 分析小圖，以俯視顯示；返回土地用途恢復原先投影。所有地表、鐵路、車站和新聞標記共用座標轉換。
  - 每三個月更新城市工程地圖，期間只在輕鐵延線通車時重畫；改變了的格閃黃框 2.5 秒，尊重減少動態設定。畫面外不重畫，樓群小圖按尺度及 DPR 快取。
  - 放大和拖動：＋／−／全港按鈕、雙擊、Ctrl＋滾輪（普通滾輪仍然捲動頁面）、拖動、兩指縮放。
  - 地標（3f.2）：12 個真實地標按真實日期出現，城市在相關方面遠遠落後時延遲；候選地建成一定規模時另有「你的發展地標」。放大後畫獨特輪廓及名稱，全港總覽為金色菱形，只在土地用途圖層顯示。詳見 [SPATIAL.md](SPATIAL.md)。
  - 地區入口方便重返十個預設地區（3f.1 加入東涌、交椅洲、將軍澳）；「城市年份」可看任內已有年度快照，年份切換保留鏡頭。過往畫面不猜測施工管道，新聞定位會返回現在。
  - 灰霧按 PM10 蓋在整個地圖上。地圖本身的顏色在淺色和深色模式相同，只有海和淡化的底色跟主題變。
- **圖層**：
  - 土地用途。
  - 人口密度：城市人口按各類住宅每格的單位數分配（公營約 3 千、私人約 2 千；鄉村用 2025 年剩下的住戶推算），是估算。
  - 樓價：私人住宅按差估署港島、九龍、新界的平均售價（100 平方米以下，每平方米實用面積），乘以城市跟真實的樓價比例；每 4 萬元一級。
  - 鐵路覆蓋：鐵路站或輕鐵站 500 米內的地方保留原色，並顯示住在 500 米內的居民比例。遊戲途中不顯示真實香港的數字。
- **遊戲畫面**：
  - 桌面：新聞欄上方的「地圖」卡，可以收起；收起與否和所選圖層記在瀏覽器。
  - 手機：底部分頁的第一個是「地圖」。
  - 工程（第 4d 步，CONTENT.md 第 6 節）：未來三年落成的單位和未來五年通車的鐵路先顯示為「建造中」格子和虛線鐵路；「你的發展」開關用粉紅框標出城市自己的新發展和鐵路。
  - 有地點的新聞旁邊有「地圖」按鈕（第 4b 步）：桌面會展開地圖卡並捲到地圖，手機會打開地圖分頁；地圖放大 4 倍到那個地方，紅圈標示 6 秒。
  - 未做：輕鐵連線（目前只畫站，天水圍北各站 2003 年 12 月起出現）。
- **結局**（`src/ui/MapCompare.tsx`，已完成）：「地圖：你的香港 vs 真實香港」。
  - 一張全闊的地圖，分隔線左邊是你的香港，右邊是真實香港；拖動分隔線（或下面的拉桿）比較。原本計劃兩張並排，但結局頁最闊 960 像素，並排時每格只有 1 個像素，看不清。
  - 年份拉桿：接手時（1997 年 7 月）、每年年底和任期最後一個月；▶ 播放每 0.7 秒一年。
  - 3e.2 加入與遊戲一致的 2.5D／俯視、地區及縮放控制；兩邊共用鏡頭，過往畫面不補畫施工進度。
  - 每一年的你的香港由當年的年度快照計算（`cityMapFrom`），所以結局不用重玩。快照記錄的是月尾的行業比重，要跟下個月月初的真實比重比較。
  - 下面的表：住宅用地、郊野及綠地、鐵路站數目、住在鐵路站或輕鐵站 500 米內的居民，你的香港和真實香港。
- **顏色及素材**：保留土地用途圖例，樓群用穩定的示意外觀。更多建築素材、鐵路細節及整體介面美術留待後續。

## 5. 測試

`tests/map.test.ts`：

- 照歷史玩（關掉隨機新聞），2026 年的城市地圖和鐵路等於真實的；真實地圖在 2026 年等於 2025 年的底圖，1997 年啟德仍是機場。
- 地圖只由城市狀況計算，所以同一種子加同樣操作，地圖必定相同。
- 不同玩法看得出分別：大力建屋，住宅格比真實多；全部部門撥款 70%，公營住宅格比真實少；郊野公園邊陲建屋，綠地格減少而邊陲有屋邨；交通撥款多，鐵路比真實多，撥款少就比真實少；創科產業重點，科學園格增加。
- 效能：計算一次地圖少於 20 毫秒（實際約 0.4 毫秒）；重畫一次少於一幀（16 毫秒，3c 再測）。

## 8. 風險
