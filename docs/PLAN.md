# WebCitySimulator 企劃（草案 v1）

> 靈感來源：《80億分之1》（1 in 8 Billion，1in8b.life）
> 概念：選一座真實城市（先做香港），從真實的起始狀態開始，由你規劃它往後幾十年的發展
> 狀態：待確認後開始實作

## 1. 《80億分之1》做了什麼

| 面向 | 內容 |
|---|---|
| 作者 / 上線 | 韓國獨立開發者 Jin Hwi-eus（Jin's Earth），2026-10-05 上線，自述用生成式 AI 約 4 小時做出第一版 |
| 核心概念 | 從全球 80 億人中隨機出生成一個人，國家、家庭、貧富都不能選 |
| 數據 | 聯合國、WHO、世界銀行等公開統計，涵蓋約 172 個國家與地區 |
| 開局設定 | 出生年代（過去 / 現在 / 未來）、抽國家的方式、人生長度（約 30 / 60 / 90 分鐘） |
| 數值 | 健康、幸福、知識、人際關係，各 0–100 |
| 進行方式 | 時間自動流動，每年 1–3 行事件；可暫停、加速、自動選擇；關鍵時刻才停下讓玩家選 |

| 其他 | 免費、免註冊、無廣告、純網頁；多語系；建議 15 歲以上 |

## 2. 遊戲概念：你來規劃香港

你是規劃者。香港陸地約七成是山地與郊野公園，土地從規劃到入伙要十年以上。
你要在有限的土地、預算與時間內，決定在哪裡開發、建甚麼、怎樣連接。

核心張力：
- **土地 vs 保育**：開發棕地、填海、動郊野公園邊陲，還是保留綠地？
- **快 vs 好**：簡約公屋快但臨時；新市鎮要十多年但完整
- **住 vs 工作**：房子都在北面、工作都在市區，通勤就會爆
- **今天 vs 將來**：花儲備做基建，還是留給下一次危機？

### 2.1 開局
- **城市**：香港（第一版只做香港）
- **起始年代**
  - **2025（現在）**：北部都會區、交椅洲填海、各條鐵路都由你決定（第一版）
  - **1997（回歸）**：可以跟真實歷史對照（第三階段）
  - **1954（石硤尾大火後）**：從木屋區開始建城（第三階段）
- **任期**：30 年或 50 年
- **種子碼**：可輸入或分享，重播同一個隨機世界

### 2.2 地圖
- 用真實地形與土地用途產生網格地圖（陸地約 1,100 平方公里，每格約 500 米）
- 每格記錄：地形坡度、現有用途（住宅、商業、工業、郊野公園、綠化地帶、農地、棕地、水體）、人口、職位、離鐵路站距離
- 以像素風格呈現，可縮放、拖曳，隨年份看到新市鎮長出來、鐵路接上

### 2.3 玩家的決策
第一版以「預設候選項目＋政策卡」為主，之後再開放自由劃區與畫鐵路。

1. **土地與新發展區**：北部都會區各分區、洪水橋 / 厦村、古洞北 / 粉嶺北、交椅洲填海、東涌東、棕地群、市區重建、改劃綠化地帶、郊野公園邊陲
   - 每個項目有面積、成本、所需年期（規劃 → 收地 → 平整 → 建屋），以及生態影響與反對程度
2. **房屋**：公私營比例、公屋 / 居屋 / 簡約公屋、劏房規管、樓市措施
3. **交通**：候選鐵路線（例如北環線、洪水橋相關路線）、道路、跨境口岸連接
4. **經濟與產業用地**：創科、金融、物流、旅遊用地的配置
5. **人口與社會**：人才計劃、安老與社區設施
6. **財政**：賣地節奏、發債、動用儲備
7. **突發事件應對**：颱風、暴雨、疫症、金融危機、移民潮

每年施政報告有預算與「政治資本」上限，最多選 3 項。

### 2.4 每一季的模擬
1. **人口**：出生、死亡、淨遷移（受宜居度、經濟、房屋影響）
2. **房屋**：住戶數 → 需求；落成量（來自各項目的進度）→ 供應 → 樓價 / 租金指數、公屋輪候時間、劏房人口
3. **經濟**：各產業增長加上隨機衝擊（依香港歷史增長分布），職位落在地圖上
4. **交通**：依住所與職位的分布和鐵路網，計算平均通勤時間
5. **財政**：收入（賣地、利得稅、薪俸稅、印花稅）減支出（經常開支、工程）→ 儲備
6. **環境**：綠地與郊野公園面積、生態價值、碳排放
7. **事件**：依歷史頻率抽事件，寫成城市新聞

### 2.5 六項城市指標（0–100）
**住屋**、**經濟**、**交通**、**環境**、**民生**（綜合居住面積、輪候、通勤、收入）、**財政**

### 2.6 結局
- 任期結束時出成績表：人口、人均居住面積、樓價入息比、公屋輪候時間、平均通勤時間、郊野公園面積、財政儲備
- 評級 S–D
- 對照：
  - 2025 開局 → 對照官方推算與規劃目標
  - 1997 開局 → 對照真實歷史
- 分享卡：你規劃的香港地圖加 3 個關鍵數字
- 「過往任期」存在 localStorage，提供匯出 / 匯入

### 2.7 內容方針
- 聚焦城市規劃與民生，不模擬選舉或政治事件
- 每項數據標註來源與年份，在「數據來源」頁公開
- 簡化的模型就明說是簡化，不假裝是預測

## 3. 數據來源（初步）

| 用途 | 來源 |
|---|---|
| 人口、住戶、GDP、人口推算 | 政府統計處 |
| 土地用途、法定圖則、長遠規劃 | 規劃署（香港土地用途統計、《香港 2030+》、北部都會區發展策略） |
| 公屋輪候、房屋落成、長遠房屋策略供應目標 | 房屋局 / 房委會 |
| 樓價與租金指數 | 差餉物業估價署 |
| 鐵路網與規劃路線 | 運輸署、港鐵、《香港主要運輸基建發展藍圖》 |
| 郊野公園範圍 | 漁護署 |
| 地圖、地形、地區邊界 | 地政總署、空間數據共享平台（CSDI） |
| 颱風與暴雨歷史 | 香港天文台 |
| 政府收支與儲備 | 財政預算案、庫務署 |
| 其他開放數據 | DATA.GOV.HK |

原始資料由 `scripts/data/` 下載並轉成精簡 JSON（地圖網格、項目清單、模型參數），放進 `src/data/`。

## 4. 技術架構

- **前端**：Vite + TypeScript + React，純靜態網站
- **地圖**：Canvas 2D 繪製像素網格地圖，支援縮放與拖曳
- **模擬引擎**：純 TypeScript 模組，不依賴介面；用有種子的亂數產生器，同一個 seed 必定重播出同一個結果
- **儲存**：localStorage（設定、過往任期），讀寫都包 try/catch
- **多語系**：繁中優先，接著英文
- **測試**：Vitest
  - 單元測試：各子模型（人口、房屋、財政）
  - **歷史回測**：從 1997 開局、照真實的落成量與鐵路通車年份跑，人口、房屋存量、樓價走勢要接近真實數字
  - **隨機事件校驗**：模擬多次，颱風等事件的平均頻率要符合歷史
- **部署**：GitHub Pages（GitHub Actions 自動建置）

### 目錄結構
```
src/
  engine/        # rng, population, housing, economy, transport, finance, environment, events, sim loop
  data/          # 產生出來的 JSON（地圖網格、候選項目、政策卡、事件、參數）
  ui/            # 開局、地圖、城市新聞、指標面板、施政報告、結局成績表、分享卡
  i18n/          # zh-Hant.json, en.json
scripts/data/    # 數據管線
tests/           # 單元測試、回測、事件校驗
docs/            # 企劃、模型說明、數據來源
```
