## 1. 《80億分之1》做了什麼

| 面向 | 內容 |
|---|---|
| 作者 / 上線 | 韓國獨立開發者 Jin Hwi-eus（Jin's Earth），2026-10-05 上線。自述用生成式 AI 約 4 小時做出第一版，之後每天多次更新 |
| 核心概念 | 從全球 80 億人中隨機「投胎」成一個人，出生國家、家庭、貧富都不能選 |
| 數據 | 聯合國、WHO、世界銀行等公開統計：預期壽命、嬰兒死亡率、收入分配、受教育年限、童婚率等，涵蓋約 172 個國家與地區（另有報導寫 141） |
| 開局設定 | 出生年代（過去 / 現在 / 未來）、抽國家的方式（依各國年出生數或依人口佔比）、人生長度（約 30 / 60 / 90 分鐘） |
| 數值 | 健康、幸福、知識、人際關係，各為 0–100 |
| 進行方式 | 每年 1–3 行事件紀錄，可暫停、加速、自動選擇；在 5、15、30、50、70 歲等階段停下；可依年齡設定「生活重心」 |
| 選擇 | 升學科系、工作、交往對象、養寵物、移居、就醫等；可花錢旅遊、買房、考證照，影響數值 |
| 結局 | 顯示死亡年齡與死因、人生回顧、S–D 評級、可分享的卡片；紀錄存在瀏覽器（「前世紀錄」），有跨裝置轉移功能 |
| 其他 | 免費、免註冊、無廣告；繁中 / 日 / 英 / 韓 / 越；建議 15 歲以上 |
| 爆紅原因 | 「國家扭蛋」帶來的同理心：玩家體會出身無法選擇。作者希望感恩能延伸成對其他生命的尊重 |
| 衍生作 | 日本粉絲做了以都道府縣為單位的在地版（「1.2億分之1」） |

可以借鏡的地方：
1. 一句話就講得完的概念，加上真實數據帶來的重量
2. 被動觀看為主，關鍵時刻才讓玩家選擇，一局有明確長度
3. 結局卡片讓人想分享，「前世紀錄」讓人想再玩
4. 純前端靜態網頁，不用登入，打開就能玩

## 2. 城市版的概念

### 推薦：A —「城市投胎」：你是這座城市的 N 分之 1

你不只被分到一個國家，而是落在一個**具體的城市與街區**：是城中村、公屋、市郊新市鎮，還是高級住宅區。
人生由城市的統計數據推動，而你住在哪裡會決定你的每一天。

跟原作的差別（不只是換皮）：

1. **城市抽籤**：先依國家城市化率決定生在城市或鄉村（全球約 57% 住在都市），再依人口權重抽城市，最後依該城市的非正式聚落比例與收入分布抽街區類型。
2. **「住哪裡」是核心取捨**：房租 vs 通勤時間 vs 空氣品質 vs 治安 vs 學區，城市怎麼樣，你的日常就怎麼樣。
3. **遷徙**：鄉村到城市、城市到城市、跨國移居。門檻依數據而定（例如戶籍制度、簽證、搬家成本）。
4. **城市會跟著你一起變老**：你的一生中城市人口成長、房租上升、地鐵通車、淹水、仕紳化、疫情。
5. **看得見的城市**：一張依城市數據產生的像素地圖，會隨年份擴張，上面標出你的家和通勤路線。
6. **結局比較**：你的一生 vs 同城平均 vs 全球平均。另有「同城不同命」：同年同城出生、不同街區的兩個人並排比較。

### 其他方向（不推薦作為主線）

- **B —「你是一座城市」**：隨機成為世界上某座城市，以市長身分經營數十年。比較像 SimCity，會失去原作「命運與同理心」的核心。
- **C — 混合**：A 加上在某些時刻以市民身分投票影響城市政策。可以在 A 完成後當擴充。

## 3. 遊戲設計（以 A 為準）

### 3.1 開局
- 出生年代：1960 / 現在 / 2050（用聯合國城市人口推估做插值）
- 抽籤方式：依出生數 / 依人口
- 人生長度：短（約 15 分鐘）/ 標準（約 30 分鐘）/ 長（約 60 分鐘）
- 可輸入種子碼（seed），重播同一段人生

### 3.2 數值（0–100）
沿用原作四項，再加兩項城市相關：
- 健康、幸福、知識、人際（同原作）
- **財務**：存款與負債的綜合
- **居住**：居住空間、安全感、通勤負擔的綜合

### 3.3 一年的流程（tick = 1 年）
1. 更新城市狀態（人口、房租指數、空氣、基建）
2. 依年齡、數值、城市條件抽 1–3 個事件
3. 碰到關鍵節點就暫停，讓玩家選擇（或自動選）
4. 套用生活重心的加權（工作 / 家庭 / 學習 / 健康 / 社交）
5. 死亡判定：國家生命表，再乘上城市修正（PM2.5、交通事故、兇殺率、高溫、醫療可及性）與財務狀態

### 3.4 選擇的範例
- 升學：就近讀書 / 跨區讀好學校（通勤 +）/ 出國
- 第一份工作：正式 / 非正式就業（依該國非正式就業比例）
- 住哪裡：市中心小套房 / 市郊大一點 / 跟家人住 / 城中村
- 租還是買、要不要買車、要不要搬到別的城市
- 遇到天災、加租、被迫搬遷時怎麼辦

### 3.5 事件類別
教育、工作、居住（加租、迫遷、抽中公屋）、通勤、健康（空污、熱浪）、天災（淹水、地震）、治安、感情與家庭、城市變遷（地鐵通車、仕紳化、新市鎮落成）、遷徙。

### 3.6 結局畫面
- 死亡年齡與原因、人生時間軸、城市在你一生中的變化
- 你 vs 同城平均 vs 全球平均
- 評級（S–D）與可下載的分享卡片（Canvas 產生圖片）
- 「前世紀錄」存在 localStorage，提供匯出 / 匯入

### 3.7 倫理與內容
- 內容提示：建議 15 歲以上
- 呈現數據時避免把某個城市或族群寫成刻板印象，每項數據都標註來源
- 自殺議題：預設不納入；若日後納入，必須附上求助資源
- 不做排名式的「哪個城市最爛」，重點放在理解

## 4. 數據來源（初步）

| 用途 | 來源 |
|---|---|
| 城市清單、人口、建成區、PM2.5、綠地、淹水 / 高溫暴露 | 歐盟 JRC GHSL Urban Centre Database（上萬個城市中心） |
| 城市人口時間序列與推估 | 聯合國 World Urbanization Prospects |
| 國家生命表、生育、婚育年齡 | 聯合國 World Population Prospects |
| 空氣品質 | WHO Ambient Air Quality Database |
| 非正式聚落比例 | UN-Habitat（SDG 11.1.1） |
| 收入分布、教育、失業、非正式就業 | 世界銀行 WDI、ILO |
| 交通事故、兇殺率 | WHO Global Status Report on Road Safety、UNODC |
| 在地模式（第 4 階段） | 香港統計處人口普查（18 區）或台灣主計總處 / 內政部（22 縣市） |

原始資料放在 `data/raw/`（不進版控或只放下載腳本），由 `scripts/data/` 轉成精簡 JSON 放進 `src/data/`。
每筆數據都保留來源與年份，在「數據來源」頁面公開。

## 5. 技術架構

- **前端**：Vite + TypeScript + React，純靜態網站
- **地圖**：Canvas 2D 程序生成像素城市（依密度、是否臨海、綠地比例、非正式聚落比例）
- **模擬引擎**：純 TypeScript 模組，不依賴 UI；用有種子的亂數產生器，確保同一個 seed 一定重播同一段人生
- **儲存**：localStorage（設定、前世紀錄），讀寫都包 try/catch
- **多語系**：繁中優先，接著英文
- **測試**：Vitest。除了單元測試，另做**統計校驗測試**：模擬 1 萬個在某城市出生的人，平均壽命、教育年限等要落在輸入數據的誤差範圍內，確保「忠於統計」
- **部署**：GitHub Pages（GitHub Actions 自動建置）

### 目錄結構
```
src/
  engine/        # rng, birth, mortality, events, choices, city-evolution, sim loop
  data/          # 產生出來的 JSON（cities, countries, events）
  ui/            # 開局、事件紀錄、數值條、城市地圖、選擇對話框、結局畫面、分享卡
  i18n/          # zh-Hant.json, en.json
scripts/data/    # 數據管線
tests/           # 單元測試與統計校驗測試
docs/            # 企劃、數據說明
```
