# WebCitySimulator 企劃（v3）

> 靈感來源：《80億分之1》（1 in 8 Billion，1in8b.life）
> 概念：從 1997 年的真實香港開始，你透過「分配施政重心」和「應對事件」重寫 1997–2026 的香港，最後跟真實的 2026 對比
> 工作名稱：《平行香港》

---

## 1. 《80億分之1》做了什麼

| 面向 | 內容 |
|---|---|
| 作者 / 上線 | 韓國獨立開發者 Jin Hwi-eus（Jin's Earth），2026-10-05 上線，自述用生成式 AI 約 4 小時做出第一版 |
| 核心概念 | 從全球 80 億人中隨機出生成一個人，國家、家庭、貧富都不能選 |
| 數據 | 聯合國、WHO、世界銀行等公開統計，涵蓋約 172 個國家與地區 |
| 操作 | 依年齡階段設定一個「生活重心」；時間自動流動，每年 1–3 行事件；關鍵時刻跳出選項；可暫停、加速、自動選擇 |
| 結局 | 死亡年齡與死因、人生回顧、S–D 評級、分享卡片、「前世紀錄」 |

### 城市版的對應

| 原作 | 平行香港 |
|---|---|
| 一個「生活重心」（單選） | 六項指標的**分配式重心**：20 點分配到住屋、經濟、交通、環境、民生、財政 |
| 每年 1–3 行事件 | 城市新聞，大事跟真實歷史一致 |
| 關鍵時刻跳出選項 | 真實的歷史關口（八萬五、入市干預、停建居屋……），選完揭曉「歷史上的選擇」 |
| 一生 | 1997 → 2026，共 30 年 |
| 死因與評級 | 城市稱號與 S–D 評級；儲備耗盡則提早結束 |
| 前世紀錄 | 過往任期 |

## 2. 為甚麼結束在現在（2026）

1. **有標準答案可以對比**：大家知道真實香港是怎樣的，「如果當年……」比預測未來更有共鳴
2. **每次抉擇都揭曉歷史**：樂趣貫穿整局，不只在結局
3. **模型可以驗證**：輸入真實政府的分配和選擇，結果必須等於真實歷史
4. **過去有數據，未來只有推算**：未來模式放到第 5 階段

## 3. 玩法

### 3.1 流程
1. 開局：輸入或隨機產生種子碼、選速度
2. 1997 年設定第一次重心分配
3. 時間自動流動，城市新聞逐月出現；抉擇事件會暫停
4. 每 5 年（2002、2007、2012、2017、2022）暫停重新分配，並揭曉上一階段「真實政府的分配（估算）」
5. 2026 年：回到現在，出成績表

### 3.2 分配式重心
- 每階段 20 點（每點 5%），分配到六項
- **財政**的點數代表存起來，轉入儲備
- 投入有邊際遞減；住屋和交通要等工程完成（約 2–6 年）才見效

### 3.3 模型：「與歷史的差距」
大事件與真實歷史一致，所以模型只計算**你跟歷史的差距**：

```
你的指標(下一年) = 你的指標(今年)
                 + 真實歷史的年度變化
                 + 你的分配與真實分配之差帶來的效果（有工程延遲）
                 + 你的抉擇與真實抉擇之差帶來的效果
                 + 指標之間的連動（例如經濟差距影響財政）
                 − 差距的自然回歸
                 + 平行時空事件（只因你的決定而發生）
```

- 完全跟隨真實的分配和抉擇，結果就等於真實歷史（自動測試會檢查）
- 種子碼決定效果的隨機浮動和平行時空事件，同一種子加同樣操作必得同一結果

### 3.4 指標與真實數據
| 指標 | 真實數據 |
|---|---|
| 住屋 | 公屋一般申請者平均輪候時間、私人住宅售價指數 |
| 經濟 | 失業率、人均本地生產總值 |
| 交通 | 鐵路網絡長度 |
| 環境 | 一般監測站可吸入懸浮粒子（PM10）年均濃度 |
| 民生 | 出生時平均預期壽命 |
| 財政 | 財政儲備 |

每項數據換算成 0–100。結局時把你跟歷史的差距換算回真實單位，例如「你的 2026：公屋輪候 3.1 年（真實 4.8 年）」。

### 3.5 事件
- **歷史事件**：亞洲金融風暴、SARS、金融海嘯、疫情、颱風、鐵路通車等，在真實年份發生
- **歷史抉擇**：八萬五、入市干預、迪士尼、停建居屋、商品及服務稅、十大基建、辣招、派錢、復建居屋、長遠房屋策略、明日大嶼、北部都會區、簡約公屋、撤辣等，選完揭曉歷史
- **平行時空事件**：只因你的決定而發生，例如供應過剩樓價急跌、司法覆核、工程超支、人才流失、財政告急
- 有政治事件的年份只呈現經濟數字，不寫政治敘事

### 3.6 結局
- 城市稱號（依你跟歷史差距最大的指標）與 S–D 評級
- 六項指標的你 vs 真實走勢圖
- 真實單位對照表
- 你的分配 vs 真實分配、你的抉擇 vs 歷史
- 「留給下一屆的工程」：2026 年後才見效的投入
- 過往任期存在瀏覽器

## 4. 技術
- Vite + TypeScript + React，純靜態網站
- 模擬引擎是純 TypeScript，不依賴介面
- 事件、數據、參數寫成資料檔
- Vitest：歷史回測（跟隨真實 = 真實歷史）、決定性、數值範圍、平衡測試
- 部署：Vercel（Git 整合，每個分支有預覽網址）；GitHub Actions 只跑測試和建置

## 5. 開發階段

| **5. 未來模式** | 從 2026 繼續玩下去 |

## 6. 數據狀態
第一版的數據因開發環境無法連上政府網站，是根據公開報道與記憶整理的**約數**，在遊戲的「數據來源」頁標明。第 2 階段會以政府統計處、房委會、差估署、環保署、庫務署的官方數據逐項核實。
