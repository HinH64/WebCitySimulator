# WebCitySimulator 企劃（v4）

> 靈感來源：《80億分之1》（1 in 8 Billion，1in8b.life）
> 概念：從 1997 年 7 月的真實香港開始，你透過**部門撥款**經營香港，觀察城市怎樣發展，最後在 2026 年跟真實的香港對比
> 工作名稱：《平行香港》
> 核心模型：見 [MODEL.md](MODEL.md)

---

## 1. 《80億分之1》做了什麼

| 面向 | 內容 |
|---|---|
| 作者 / 上線 | 韓國獨立開發者 Jin Hwi-eus（Jin's Earth），2026-10-05 上線，自述用生成式 AI 約 4 小時做出第一版 |
| 核心概念 | 從全球 80 億人中隨機出生成一個人，國家、家庭、貧富都不能選 |
| 數據 | 聯合國、WHO、世界銀行等公開統計，涵蓋約 172 個國家與地區 |
| 操作 | 依年齡階段設定一個「生活重心」；時間自動流動，每年 1–3 行事件；關鍵時刻跳出選項；可暫停、加速、自動選擇 |
| 結局 | 死亡年齡與死因、人生回顧、S–D 評級、分享卡片、「前世紀錄」 |

### 城市版的對應

| 原作 | 平行香港 |
|---|---|
| 生活重心 | **部門撥款**：唯一的主要操作，調整後觀察城市發展 |
| 時間自動流動 | 時間一直流動，所有面板隨時打開調整，不打斷玩家；何時暫停由玩家設定 |
| 每年 1–3 行事件 | 城市新聞，大事跟真實歷史一致 |
| 關鍵時刻跳出選項 | 收件匣裡的歷史抉擇，有限期，不強制暫停 |
| 健康、幸福等數值 | 兩個主要數值（庫房、人口）加六項發展指標 |
| 死因與評級 | 城市稱號與 S–D 評級；財政崩潰則提早結束 |
| 前世紀錄 | 過往任期 |

## 2. 為甚麼結束在現在（2026）

1. **有標準答案可以對比**：大家知道真實香港是怎樣的，「如果當年……」比預測未來更有共鳴
2. **結局揭曉歷史**：每個抉擇歷史上怎樣選、你的 2026 跟真實 2026 差多少，都在結局一次過揭曉
3. **模型可以驗證**：照真實政府的做法玩一局，結果要落在真實數字的誤差範圍內（自動測試會檢查）
4. **過去有數據，未來只有推算**：未來模式放到第 5 階段

## 3. 玩法（摘要，詳見 MODEL.md）

| 層次 | 內容 |
|---|---|
| 主要操作 | **預算面板**：六個部門的撥款水平（50%–200%）。低於 100% 服務變差，高於 100% 擴建，但有工程延遲 |
| 次要操作 | 稅率（薪俸稅、利得稅、差餉）、債務、長期政策、收件匣抉擇 |
| 主要數值 | **庫房**（億元）、**人口**（萬人），每月更新 |
| 觀察 | 六項發展指標；需求與供應面板附原因；人口與吸引力面板；城市新聞；年度報告 |
| 系統自動計算 | 保養開支、工程延遲、收入、吸引力帶動移民、經濟五行業和歷史衝擊 |
| 自動暫停（⚙） | 定期暫停（不暫停／每 1、3、5 年）、抉擇時暫停、危機時暫停、打開面板時暫停 |
| 結局 | 你的 2026 vs 真實 2026（真實單位）、歷史揭曉、預算比例對比、城市稱號與評級 |

內容方針：
- 聚焦城市規劃與民生，不模擬選舉或政治事件；有政治事件的年份只呈現經濟數字。
- 每項數據標註來源與年份。
- 模型是簡化的遊戲模型，會明說，不假裝是預測。

## 4. 原型（第 0 階段，已完成）

驗證了「真實歷史 + 分配 + 抉擇 + 結局對比」這個概念：
- 20 點分配到六項指標，每 5 年重新分配
- 模型只計算玩家跟歷史的差距
- 17 個歷史抉擇（選完即時揭曉）、38 個歷史事件、14 個平行時空事件
- 結局有走勢圖、真實單位對照、過往任期

試玩後決定改變的地方：
- 分配和指標一對一、指標太抽象 → 改為部門撥款，加入實體建設和需求與供應
- 欠缺具體的錢和人口 → 加入庫房和人口
- 每次抉擇揭曉歷史太打擾 → 改到結局揭曉
- 強制暫停打斷觀看 → 改為玩家自己設定

## 5. 技術

- Vite + TypeScript + React，純靜態網站
- 模擬引擎是純 TypeScript，不依賴介面，每月計算一次
- 事件、政策、數據、參數寫成資料檔
- Vitest：決定性、會計恆等（每月庫房變化 = 收入 − 開支）、歷史基準校準（誤差範圍）、平衡測試
- 部署：Vercel（Git 整合，每個分支有預覽網址）；GitHub Actions 只跑測試和建置
- 暫時不需要資料庫：數據跟網頁一起打包，玩家紀錄存在瀏覽器

## 6. 開發階段

每個階段完成時都可以在 Vercel 試玩。

| 階段 | 內容 | 完成標準 |
|---|---|---|
| **0. 原型**（已完成） | 見第 4 節 | 驗證概念可行 |
| **1. 核心玩法**（已完成） | [MODEL.md](MODEL.md) 的全部內容：部門撥款、庫房、人口、稅率、債務、政策、需求與供應、吸引力與移民、經濟五行業、收件匣、自動暫停設定、新結局 | 歷史基準玩法通過誤差測試；平衡測試通過；可以玩完一整局 |
| **2. 真實數據與公開測試** | 用官方數據取代約數、完善數據來源頁、按試玩意見調整平衡、在 Vercel 正式上線 | 每個數字都有官方來源；公開網址可玩 |
| **3. 像素地圖** | 把建設量畫成香港地圖：新市鎮、鐵路、填海；加入圖層，例如人口密度、樓價、鐵路覆蓋 | 地圖隨建設變化 |
| **4. 內容擴充** | 更多事件；暫緩的機制（舊樓老化、施政阻力、追蹤市民、里程碑）；1954、1973 開局；分享卡；英文版 | 按需要逐項完成 |
| **5. 未來模式** | 由 2026 繼續玩下去，用官方人口和經濟推算 | 可以玩到例如 2056 年 |
| **6. 更多城市** | 其他城市，或像原作一樣「隨機抽一座世界城市」 | 至少一個新城市 |

**可選支線：玩家統計**（例如「42% 玩家選擇停建居屋」）需要資料庫。等第 2 階段上線、有玩家之後再決定。

## 7. 數據狀態

目前的數據因開發環境無法連上政府網站，是根據公開報道與記憶整理的**約數**，在遊戲的「數據來源」頁標明。第 1 階段繼續用約數做校準；第 2 階段會以政府統計處、房委會、差估署、環保署、庫務署等官方數據逐項核實。
