# 平行香港 1997–2026（WebCitySimulator）

從 1997 年 7 月 1 日的真實香港開始，你分配施政重心、在真實的歷史關口作出選擇，最後在 2026 年把你的香港跟真實的香港對比。靈感來自網頁人生模擬遊戲《80億分之1》。

企劃見 [docs/PLAN.md](docs/PLAN.md)。

## 玩法

- **撥款（主要操作）**：調整六個部門的撥款水平。100% 維持現有服務；低於 95% 服務會慢慢變差；高於 100% 會擴建，例如公營房屋、鐵路、病床，但工程要幾年才見效。
- **觀看**：時間一直流動，頂部顯示庫房和人口，左邊是六項發展指標。金融風暴、SARS、金融海嘯、疫情照真實歷史發生。
- **其他工具（隨時可用，不打斷時間）**：
  - 稅率：薪俸稅、利得稅、差餉
  - 債務：發債和還債
  - 長期政策：13 項
  - 需求面板：城市缺甚麼、為甚麼
  - 人口面板：吸引力和移民
- **收件匣**：18 個歷史抉擇，例如八萬五、停建居屋、十大基建、辣招、北部都會區。每個限期 12 個月，到期維持現狀。
- **自動暫停**：在 ⚙ 設定，可以定期暫停、收到抉擇時暫停、財政危機時暫停，或操作面板時暫停。
- **結局**：2026 年 10 月回到現在，用真實數字比較你的香港和真實香港，並揭曉每個關口歷史上怎樣選。

## 開發

```bash
npm install
npm run dev        # 本機開發
npm test           # 單元測試、歷史回測、平衡測試
npm run build      # 型別檢查並建置到 dist/
```

結構：

```
src/engine/   模擬引擎（純 TypeScript，不依賴介面）
src/data/     真實數據、預算結構、政策、歷史事件與抉擇、城市動態事件
src/ui/       React 介面
tests/        Vitest 測試
```

### 模型

詳見 [docs/MODEL.md](docs/MODEL.md)。每月計算一次，每個數值都是「真實數值 + 你的決定造成的差距」：

- 撥款高於或低於真實政府，會改變建設量和設施質素。
- 稅率和政策改變收入、樓價和吸引力。
- 吸引力決定移民；移民又影響住屋、就業和收入。

`tests/engine.test.ts` 會檢查兩件事：
- 完全照真實政府的撥款和抉擇去做，每年的數字都等於真實歷史；
- 每月的收支平衡。

`tests/balance.test.ts` 用多種玩法自動試玩，檢查評級分佈是否合理。

## 數據

第一版的數據是根據公開報道整理的**約數**，部分年份為估算，因為開發環境無法連上政府數據網站。每個系列的來源和狀態記錄在 `src/data/real.ts`，遊戲內的「數據來源與模型」頁也有列出。第 2 階段會以官方數據逐項核實。

「真實政府的施政重心」是按開支比例和主要政策估算的，只作比較之用。

## 部署

網站部署在 Vercel，透過 Vercel 的 Git 整合自動部署：

- 推送到 `main`：更新正式網址。
- 推送到其他分支或開 PR：產生獨立的預覽網址。

在 Vercel 匯入這個 repo 時會自動偵測到 Vite（Build Command `npm run build`，Output Directory `dist`），不用另外設定。

GitHub Actions（`.github/workflows/ci.yml`）只負責在每次推送和 PR 時跑測試和建置，不負責部署。
