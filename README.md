# 平行香港 1997–2026（WebCitySimulator）

一個網頁版的《模擬城市》／《Cities: Skylines》，但不是從一塊空地開始，而是從一座真實存在的城市開始：1997 年 7 月 1 日的香港。你分配部門撥款，看著城市一年一年發展到 2026 年。真實的大事會照樣發生；你的香港會走成怎樣，就看你的決定。結局不打分，而是把你的香港跟真實的香港放在一起比較。靈感來自網頁人生模擬遊戲《80億分之1》。

企劃見 [docs/PLAN.md](docs/PLAN.md)。

## 玩法

- **撥款（主要操作）**：調整六個部門的撥款水平。100% 維持現有服務；低於 95% 服務會慢慢變差；高於 100% 會擴建，例如公營房屋、鐵路、病床，但工程要幾年才見效。
- **觀看**：時間一直流動。城市新聞是畫面的主角；頂部顯示庫房、人口、民望和六項發展指標，新聞上方是「市民最關心」。
  - 大事：每年都有，金融風暴、SARS、金融海嘯、颱風、疫情照真實歷史發生。衝擊大小看你的城市有沒有準備：病床不足的城市疫情打擊較大，設施失修的城市颱風後要多花錢修復，儲備不足三個月開支的城市金融危機衝擊較大。
  - 城市新聞：約 90 個一般事件，按你的城市狀況隨機發生（輪候長就多劏房新聞，新鐵路通車就多乘客創新高）。
  - 城市動態：城市越過某個水平時出現，例如失業率高企、移民潮、樓價急跌、儲備充裕、醫院走廊加床。民望告急時要選擇下一份施政報告集中處理哪個問題。
  - 有地點的新聞旁邊有「地圖」按鈕，按一下地圖會移到那個地方，例如新機場、馬頭圍道塌樓、颱風水浸的屋苑。
  - 統計數字：按政府公布數字的時間表報道你的城市，例如失業率創幾年新高、經濟連續幾季收縮、出現通縮、樓價超越 1997 年高位、年中人口和出生人數。照歷史玩會看到真實的數字。
  - 里程碑：人口、公營房屋、鐵路、儲備、預期壽命突破整數。
- **地圖**：按你的城市自動建造的像素地圖，每格 250 米。多建屋、鐵路、某個行業，或在郊野公園邊陲建屋，地圖都會跟著變；新落成的地方會閃一下。四個圖層：土地用途、人口密度、樓價、鐵路覆蓋。桌面版在新聞上方，可以收起；手機版在底部的「地圖」分頁。
- **其他工具（右邊面板，隨時可用，不打斷時間）**：預算、需求、人口、稅率、政策、債務。手機上由底部分頁打開。
- **一般政策**：像 SimCity 的法令或 Cities: Skylines 的政策，名稱通用，一開局就可以用。共 19 項，分房屋及土地、交通、經濟及就業、社會及醫療、環境、稅務六類，例如房屋供應目標、額外印花稅、乘車優惠、最低工資、垃圾徵費、銷售稅。政策只由你改變，不會自動跟隨歷史；稅率也一樣，開局是 1997 年的稅率，之後只由你調整。
- **歷史抉擇（待決定）**：31 個有名有姓的歷史關口，例如八萬五、金融保衛戰、SARS 後的防疫準備、停建居屋、十大基建、2 元乘車優惠、保就業、北部都會區。抉擇會設定一般政策，例如「訂下八萬五」把房屋供應目標調到「進取」；有些到某月才生效，例如最低工資 2010 年立法、2011 年 5 月實施。部分抉擇只在相關時出現，例如沒有訂下八萬五，就不會有「八萬五去留」。每個限期 12 個月，到期維持現狀。
- **民望**：頂部顯示 0–100。市民最關心的問題嚴重，而政府沒有回應（加撥款、改政策、回覆抉擇），民望會慢慢下跌；服務失修、加稅和不受歡迎的政策（銷售稅、垃圾徵費、郊野公園邊陲建屋）也會扣民望。需求面板顯示市民覺得政府在每個範疇有沒有回應。連續一年低於 25 就會被迫下台，跟財政崩潰一樣提早結束。民望不改變城市的任何數字。
- **自動暫停**：在 ⚙ 設定，可以定期暫停、收到抉擇時暫停、危機時暫停（財政或民望），或操作面板時暫停。
- **結局**：不評分（提早結束的城市稱號是「財政懸崖」或「被迫下台」）。最頂是城市稱號和幾句總結，把你的香港跟真實的香港比較：六項指標幾多項較好、幾多項較差，最好和最差的是哪幾項及背後的數字，以及財政和人口。之後是兩者的地圖（拖動分隔線比較，年份拉桿可以由 1997 年播到結局）、走勢圖和數字、每個關口歷史上怎樣選，以及兩者的政策和稅率對比。

## 開發

```bash
npm install
npm run dev        # 本機開發
npm test           # 單元測試、歷史回測、平衡測試
npm run build      # 型別檢查並建置到 dist/
npm run images     # 用 Chrome 重新產生分享預覽圖和主畫面圖示（scripts/images → public/）
npm run data:map   # 重新下載地圖數據（土地用途、鐵路站、分區樓價）；--skip-land 跳過較慢的土地用途
```

結構：

```
src/engine/   模擬引擎（純 TypeScript，不依賴介面）
src/data/     真實數據、預算結構、政策、歷史事件與抉擇、城市動態、一般城市事件
src/ui/       React 介面
tests/        Vitest 測試
```

### 模型

詳見 [docs/MODEL.md](docs/MODEL.md)。每月計算一次，每個數值都是「真實數值 + 你的決定造成的差距」：

- 撥款高於或低於真實政府，會改變建設量和設施質素。
- 稅率和政策改變收入、樓價和吸引力。
- 吸引力決定移民；移民又影響住屋、就業和收入。

`tests/engine.test.ts` 會檢查：
- 完全照真實政府的撥款、政策和抉擇去做（關掉隨機城市新聞），每年的數字都等於真實歷史；打開城市新聞，結果仍然接近真實歷史；
- 政策不會在玩家沒有行動時改變；
- 每月的收支平衡。

`tests/balance.test.ts` 用多種玩法自動試玩，用一個玩家看不到的內部分數，檢查各種玩法的高低是否合理。

## 數據

第 2 階段正逐項把數據換成官方數字。人口、出生、死亡、年齡結構、住戶人數、失業率、教育程度、人均本地生產總值、物價和預期壽命已取自政府統計處的數據 API 和衞生署的公開數據；私人住宅單位和樓價指數取自差估署的開放數據；公營房屋單位由統計年刊和房委會《房屋統計數字》整理（只有 PDF 的年份是人手抄錄，寫在下載程式內並註明出處）；財政儲備、政府開支和收入來源比例取自統計處和庫務署（儲備扣除 2019 年起計入儲備的發債所得，因為遊戲中真實的香港沒有債務）：

```bash
npm run data:official   # 重新下載，產生 src/data/official.ts
```

未公布全年數字的年份（例如 2026 年）用已公布的月份或季度估算，並在數據來源頁標明。其餘系列（公屋輪候時間、各部門開支比例和真實政府撥款水平、鐵路、空氣、醫療安老、郊野公園、單程證、各行業比重）沒有可以直接下載的完整官方數據，仍是根據公開報道整理的**約數**，記在 `docs/PLAN.md` 第 7 節，留待之後補上。市場利率的官方數據（金管局 API）已加入下載程式，但 API 暫時封鎖了本機的連線，下載成功後才會換上。每個系列的來源和狀態記錄在 `src/data/real.ts`，遊戲內的「數據來源與模型」頁也有列出，官方系列附上原始數據表的連結。

「真實政府的撥款水平」是按開支比例和主要政策估算的，只用來在結局揭曉時比較。

地圖的數據（詳見 `docs/MAP.md`）：規劃署 2025 年土地用途網格、地政總署的鐵路站坐標、差估署的私人住宅分區平均售價，由 `npm run data:map` 下載；1997 年後的發展項目、鐵路路線和候選發展地按公開資料人手整理，寫在 `src/data/mapProjects.ts` 並註明出處。

## 部署

網站部署在 Vercel（正式網址 <https://web-city-simulator.vercel.app/>），透過 Vercel 的 Git 整合自動部署：

- 推送到 `main`：更新正式網址。
- 推送到其他分支或開 PR：產生獨立的預覽網址。

在 Vercel 匯入這個 repo 時會自動偵測到 Vite（Build Command `npm run build`，Output Directory `dist`），不用另外設定。

`index.html` 的分享預覽（`og:url`、`og:image`）和 canonical 連結寫死了正式網址；如果改用自訂網域，要一併更新。

GitHub Actions（`.github/workflows/ci.yml`）只負責在每次推送和 PR 時跑測試和建置，不負責部署。
