# 平行香港 1997–2026（WebCitySimulator）

從 1997 年 7 月 1 日的真實香港開始，你分配施政重心、在真實的歷史關口作出選擇，最後在 2026 年把你的香港跟真實的香港對比。靈感來自網頁人生模擬遊戲《80億分之1》。

企劃見 [docs/PLAN.md](docs/PLAN.md)。

## 玩法

- **分配**：把 20 點分到住屋、經濟、交通、環境、民生、財政，每 5 年重新分配一次，也可隨時調整（下一年生效）。
- **觀看**：時間自動流動，金融風暴、SARS、金融海嘯、疫情等照真實歷史發生。
- **抉擇**：八萬五、入市干預、停建居屋、十大基建、辣招等 17 個歷史關口，選完揭曉歷史上的選擇；你的決定也會引發「平行時空」事件。
- **對照**：2026 年出成績表，包括城市稱號、評級、走勢圖，以及以真實單位顯示的對比，例如公屋輪候年期和財政儲備。

## 開發

```bash
npm install
npm run dev        # 本機開發
npm test           # 單元測試、歷史回測、平衡測試
npm run build      # 型別檢查並建置到 dist/
```

結構：

```
src/engine/   模擬引擎（純 TypeScript，不依賴介面）
src/data/     真實數據、歷史事件與抉擇、平行時空事件
src/ui/       React 介面
tests/        Vitest 測試
```

### 模型

大事件跟真實歷史一致，所以引擎只計算你跟歷史的差距：

- 真實的年度變化
- 你的分配與真實分配之差帶來的效果：有工程延遲和邊際遞減，指標越弱投入越見效
- 你的抉擇與真實抉擇之差帶來的效果
- 指標之間的連動
- 差距每年自然收窄一部分

`tests/engine.test.ts` 會檢查：完全跟隨真實的分配和抉擇，結果必須等於真實歷史。

## 數據

第一版的數據是根據公開報道整理的**約數**，部分年份為估算，因為開發環境無法連上政府數據網站。每個系列的來源和狀態記錄在 `src/data/history.ts`，遊戲內的「數據來源與模型」頁也有列出。第 2 階段會以官方數據逐項核實。

「真實政府的施政重心」是按開支比例和主要政策估算的，只作比較之用。

## 部署

推送到 `main` 後，GitHub Actions 會測試、建置並部署到 GitHub Pages。第一次使用前，要在 repo 的 **Settings → Pages** 把 Source 設為 **GitHub Actions**。
